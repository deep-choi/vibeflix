글자

가장 작은 글자는 12px이에요(대문자 라벨만 11px). 휴대폰 입력칸은 16px이라 확대되지 않아요.

3xl · 30상상을 플레이하다
2xl · 24모달 제목
xl · 20섹션 제목
md · 15본문 텍스트 — 바이브 코딩으로 만든 작품을 소개해요.
sm · 13라벨, 버튼, 보조 설명
xs · 12힌트, 메타 정보, 배지
kicker · 11SECTION KICKER

버튼

.btn + 종류(primary · danger · ghost · link · icon) + 크기(small 36 · 기본 44 · large 52). 터치 화면에서 small은 40px이 돼요.

종류
크기
상태
블록 (모달·폼의 단일 주 버튼)

입력

모달·.field 안의 입력칸. 포커스는 라임 테두리와 옅은 링, 오류는 빨간 테두리와 메시지.

칩 · 배지

칩은 누르는 것(하나만 고르면 꽉 찬 라임, 여러 개 고르면 옅은 라임), 배지는 보기만 하는 라벨이에요.

칩 — 하나만 선택
칩 — 여러 개 선택
배지
기본✓ 해결됨공개성인 소재버그 제보피드백

탭

2~4개를 바꾸는 .segmented, 화면 영역을 바꾸는 .tabs.

알림 · 토스트

페이지 안의 안내는 .alert, 잠깐 뜨는 결과는 DS.toast() — 열린 모달 위에도 보여요.
